## Evaluation setup

- Target: failure within the next 24 operational cycles (cycles, not hours; horizon pending team approval)
- Split: engine-disjoint 70% train / 15% validation / 15% test (team `temporal_train_val_test_split`)
- Scored rows: validation cycles >= 30 (2775 rows, 15 engines), so row models and the GRU use identical rows
- Class balance on scored rows: 375 positive / 2400 negative (13.5% positive); an all-negative predictor already scores 86.5% accuracy
- Threshold: 0.5 for every model, not tuned. Test split not used.
- Imputation and scaling fitted on training rows only; trees use scikit-learn HistGradientBoosting (interim stand-in for the XGBoost/LightGBM model).
- Engineered features: 242 columns; filtered proposal: 166
- GRU: not re-run in this report (use `--with-gru`); see `reports/baseline_gru_comparison.md` for the team's run.
